Substring method in java

Solution
public class SubstringExample {
    public static void main(String[] args) {
        String str = "Hello, World!";
        
        // Extracting substring from index 7 to the end
        String sub1 = str.substring(7);
        System.out.println("Substring from index 7: " + sub1);

        // Extracting substring from index 0 to 5 (exclusive)
        String sub2 = str.substring(0, 5);
        System.out.println("Substring from index 0 to 5: " + sub2);
    }
}

Key Points for Interview
substring(beginIndex) extracts from the given index to the end.
substring(beginIndex, endIndex) extracts from beginIndex to endIndex - 1.
Indexing starts from 0 in Java.
Substring method does not modify the original string (Strings are immutable).
Using substring() incorrectly (e.g., out-of-range indices) will throw StringIndexOutOfBoundsException.
