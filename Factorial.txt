Program to find factorial of a Number in Java

import java.util.Scanner;

public class Factorial {
    
    // Recursive method to calculate factorial
    public static long factorial(int num) {
        // Base case: factorial of 0 or 1 is 1
        if (num == 0 || num == 1) {
            return 1;
        } else {
            // Recursive case: num * factorial of (num - 1)
            return num * factorial(num - 1);
        }
    }

    public static void main(String[] args) {
        // Create a Scanner object to take input from the user
        Scanner scanner = new Scanner(System.in);

        // Prompt the user to enter a number
        System.out.print("Enter a number: ");
        int num = scanner.nextInt(); // Read the user input number

        // Call the recursive method and print the result
        long result = factorial(num);
        System.out.println("Factorial of " + num + " is " + result);

        // Close the scanner to avoid resource leak
        scanner.close();
    }
}

Base Case: When num is 0 or 1, the factorial is 1. This is the stopping condition for the recursion.
Recursive Case: If num is greater than 1, we multiply num by the result of factorial(num - 1). This means the function keeps calling itself with decreasing values of num until it reaches the base case.
Main Method:

The main method still uses a Scanner object to take input from the user.
After getting the number, it calls the factorial method and prints the result.

Base Case and Recursive Calls:

Each call to factorial(num) reduces the problem size by calling factorial(num - 1), and this continues until the base case is met. The result is then computed by multiplying num by the result of the recursive call.

Key Points for Interview:
Recursion: The function calls itself with a smaller problem size (num - 1) until a base case is reached.
Base Case: Necessary to terminate recursion, ensuring that the function doesn’t call itself indefinitely.
Efficiency: While recursion can make the code simpler and more elegant, it can also lead to a stack overflow error if the recursion depth is too deep (e.g., for very large numbers).

import java.util.Scanner;

public class Factorial {
    public static void main(String[] args) {
        // Create a Scanner object to take input from the user
        Scanner scanner = new Scanner(System.in);

        // Prompt the user to enter a number
        System.out.print("Enter a number: ");
        int num = scanner.nextInt(); // Read the user input number

        // Initialize a variable to hold the factorial result, starting from 1 (as factorial of 0 is 1)
        long factorial = 1;

        // Loop to calculate the factorial
        for (int i = 1; i <= num; i++) {
            factorial *= i; // Multiply the current factorial by the loop counter
        }

        // Output the result
        System.out.println("Factorial of " + num + " is " + factorial);

        // Close the scanner to avoid resource leak
        scanner.close();
    }
}
