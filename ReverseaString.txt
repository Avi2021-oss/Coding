Program to Reverse a String in Java

Solution:
import java.util.Scanner;

public class ReverseString {
    public static void main(String[] args) {
        // Step 1: Create a Scanner object to take input from the user
        Scanner scanner = new Scanner(System.in);
        
        // Step 2: Prompt the user to enter a string
        System.out.print("Enter a string: ");
        String input = scanner.nextLine();  // Read user input
        
        // Step 3: Reverse the string
        String reversed = reverseString(input);
        
        // Step 4: Display the reversed string
        System.out.println("Reversed string: " + reversed);
        
        // Step 5: Close the scanner to prevent resource leaks
        scanner.close();
    }

    // Function to reverse a string
    public static String reverseString(String str) {
        // Convert the string to a character array
        char[] charArray = str.toCharArray();
        int left = 0, right = charArray.length - 1;

        // Swap characters from both ends moving toward the center
        while (left < right) {
            // Swap characters
            char temp = charArray[left];
            charArray[left] = charArray[right];
            charArray[right] = temp;
            
            // Move towards the center
            left++;
            right--;
        }
        
        // Convert character array back to string and return
        return new String(charArray);
    }
}

Alternative Approaches
Using StringBuilder

java

public static String reverseString(String str) {
    return new StringBuilder(str).reverse().toString();
}
Uses StringBuilder's built-in reverse() method.
Using Recursion

java

public static String reverseString(String str) {
    if (str.isEmpty()) return str;
    return reverseString(str.substring(1)) + str.charAt(0);
}
Uses recursion to reverse the string.
