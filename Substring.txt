Substring method in java

Solution
public class SubstringExample {
    public static void main(String[] args) {
        String str = "Hello, World!";
        
        // Extracting substring from index 7 to the end
        String sub1 = str.substring(7);
        System.out.println("Substring from index 7: " + sub1);

        // Extracting substring from index 0 to 5 (exclusive)
        String sub2 = str.substring(0, 5);
        System.out.println("Substring from index 0 to 5: " + sub2);
    }
}

Key Points for Interview
substring(beginIndex) extracts from the given index to the end.
substring(beginIndex, endIndex) extracts from beginIndex to endIndex - 1.
Indexing starts from 0 in Java.
Substring method does not modify the original string (Strings are immutable).
Using substring() incorrectly (e.g., out-of-range indices) will throw StringIndexOutOfBoundsException.

Java Program to Find Substrings of a String

Solution:
Java Program to Find Substrings of a String:
java
Copy
Edit
public class SubstringExample {
    public static void main(String[] args) {
        // Step 1: Define the input string
        String input = "abc";

        // Step 2: Find and print all substrings
        System.out.println("Substrings of \"" + input + "\":");

        // Step 3: Outer loop to select the starting point of the substring
        for (int i = 0; i < input.length(); i++) {
            
            // Step 4: Inner loop to select the ending point of the substring
            for (int j = i + 1; j <= input.length(); j++) {
                
                // Step 5: Extract and print the substring from index i to j
                System.out.println(input.substring(i, j));
            }
        }
    }
}

Interview Explanation:
Outer Loop: Loops through each starting index i of the string.
Inner Loop: Loops through each possible ending index j, where j > i, to generate substrings starting at index i and ending at index j-1.
Substring Extraction: The substring() method is used to get a portion of the string from index i to j-1. This is repeated for all possible combinations of i and j.
